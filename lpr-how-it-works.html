LPR — License Plate Recognition

How the iplus system automatically identifies, tracks, and manages vehicles entering and exiting a condominium using camera-based plate recognition.

Overview

What is LPR?

LPR (License Plate Recognition) — also called ANPR (Automatic Number Plate Recognition) — is an AI-powered camera system that reads vehicle number plates automatically as vehicles pass through entry/exit barriers. In iplus, it is powered by Hikvision hardware cameras and is the backbone of automated vehicle access control at condominiums.

📷

Camera reads the plate

A Hikvision camera at the gate captures the plate image, runs OCR, and sends the plate text to iplus in real time.

🔍

System looks it up

iplus checks the plate against registered residents, active visitor passes, and the blacklist database.

🔔

Smart notifications fire

Residents get notified when their visitor arrives. Staff get alerted for blacklisted or suspicious vehicles.

📋

Full audit trail logged

Every entry and exit is timestamped, photographed, and stored — giving security a complete vehicle access history.

Actors

Who is Involved?

📷

Hikvision LPR Camera

Physical hardware mounted at entry/exit gates. Captures plate, runs OCR, and sends a webhook to iplus with the plate number and camera IP.

🏠

Resident

Registers their own vehicle plate. Receives push notifications when a registered visitor's car arrives.

🛡️

Security Guard

Uses the iplus Security Guard mobile app to manually register visitor vehicles, log entry/exit, and view the access log.

🏢

Property Management

Configures the system: sets visit time windows, max visitor vehicles, blacklist vehicles, and notification templates.

⚙️

iplus Server

Acts as the integration hub — receives camera webhooks, matches plates, triggers notifications, and stores all logs.

End-to-End Flow

How It Works — Step by Step

1
Vehicle approaches the gate
A car or motorcycle drives up to the condominium entry or exit barrier.
2
Hikvision camera captures and reads the plate
The LPR camera performs real-time OCR on the number plate. This happens in milliseconds.
Camera sends a HTTP POST (XML/JSON) to:
POST /externalsync/hikvisioncamera

Payload includes: condoId ipAddress (camera ID) licensePlate plate image file
3
iplus identifies the camera (entry or exit)
The server uses the camera's IP address to look up the camera record and determine its type.
Looks up: hikvision_camera table using ipAddress

camera_type = 1 → Entry camera (vehicle coming IN)
camera_type = 2 → Exit camera (vehicle going OUT)
4
iplus logs the camera event
Every plate read is immediately recorded regardless of whether the vehicle is known.
Stored procedure: hikcameralog_ver3
Writes to: hikcameralog table
Fields: license_plate_no, camera_id, condo_id, timestamp, image reference
5
iplus checks the plate against all databases
The plate number is looked up against three sources simultaneously.
Check 1 — Is it a RESIDENT vehicle?
Table: unit_parking_spot (resident registered vehicles)

Check 2 — Is it a VISITOR with a valid pass?
Table: unit_visitor_pass (security guard registered visitor vehicles)

Check 3 — Is it BLACKLISTED?
Table: hikvision_parking_black_list
6
Decision: What happens next?
Based on the lookup result, one of four paths is taken.
✓ Known Resident Vehicle → Log entry, no notification needed (automatic access)

✓ Valid Visitor Pass → Log entry + notify resident that visitor has arrived

⚠ Repeated Entry → If same vehicle enters within the configured time window → alert staff

✗ Blacklisted Vehicle → Log + immediately alert security staff with plate image
7
Parking log is created
A detailed record is written with full context of the access event.
Entry camera → hikvision_parking_log (new record, status = IN)
Exit camera → hikvision_parking_out_log (updates existing record, status = OUT)

Stored fields: plate_no, driver_name, unit_no, condo_id, camera_id, entry_time, exit_time, image_url, vehicle_type
8
Plate image is stored
The captured plate image is uploaded to cloud storage and linked to the log record.
Upload path: s3/condo/{condoId}/unit_visitor_pass_vehicle/
ref_table = 81 (hikvision_parking_log)
ref_table = 77 (hikcameralog)
9
Push notifications are sent
The right people are notified based on the vehicle type and event.
Visitor arrives → Resident gets: "Your visitor [driver name] has arrived"
Repeated vehicle → Security staff gets: alert with plate + image
Blacklist vehicle → Security staff gets: urgent alert with plate + image

API Reference

Key API Endpoints

Endpoint Direction Purpose
POST /externalsync/hikvisioncamera Camera → iplus Main LPR webhook — camera sends plate + image to iplus on every detection
POST /securityguard/vehicle-add App → iplus Security guard manually registers a visitor vehicle and creates a visitor pass
POST /securityguard/vehicle-list App → iplus Lists all registered and visitor vehicles for the condo on a given date
POST /securityguard/vehicle-access-log App → iplus Full entry/exit access history — filterable by date, plate, vehicle type, status

Security

Security & Privacy Features

Encrypted Plate Numbers

All plate numbers are stored encrypted in the database using AES_ENCRYPT with a private database key. Plain text plates are never stored at rest.

Blacklist Management

Property management can flag any plate. Every blacklisted vehicle detection fires an immediate alert to the nominated security staff list with plate image and timestamp.

Repeated Entry Detection

If the same plate is detected again within the configured time window (e.g., 30 minutes), it is flagged as a suspicious repeated entry and staff are notified.

Full Audit Trail

All plate changes (resident updates their vehicle plate) are tracked in unit_parking_spot_before_update with old value, new value, user, and timestamp.

Notifications

Who Gets Notified and When

🏠

Resident — Visitor Arrived

When a vehicle with an active visitor pass enters, the resident who created the pass receives a push notification with the visitor's name and arrival time.

🚨

Security Staff — Blacklisted Vehicle Detected

Configured staff list (from staff_list_for_black_list_vehicle) receives an urgent push notification with the plate, image, and location. Template: "[vehicle] blacklisted vehicle detected at [condoname]"

⚠️

Security Staff — Repeated Vehicle Entry

If the same plate enters more than once within the time window, staff are notified. Template configurable per condo in hikvision_setting.

📧

Resident — Vehicle Registration Approved

When management approves a resident's parking spot / vehicle registration, a push and email notification is sent via security_add_vehicle_notification stored procedure.

Visitor Flow

How a Visitor's Vehicle Gets a Pass

The LPR camera can only recognise a visitor's vehicle if a pass has been created for it first. Here is how that happens:

A
Resident pre-registers visitor (optional)
Resident can create a visitor pass in advance from the iplus app — entering the visitor's name, plate number, and valid dates.
B
Security guard registers vehicle at gate
More commonly, the security guard uses the iplus Security Guard app when a visitor arrives — collecting plate, vehicle type, driver name, contact, and purpose.
API: POST /securityguard/vehicle-add
Calls stored procedure: security_vehicle_add_ver2
Creates: unit_visitor_pass record + hikvision_parking entry
Pushes plate to Hikvision hardware allowlist automatically
C
iplus syncs plate to camera hardware
The approved plate is pushed to the Hikvision camera's allowlist so the barrier can open automatically on next entry.
Direction: iplus → Hikvision Camera (PUT request)
Plate encoded as base64 hex for camera API compatibility
Sync tracked in: hikvision_parking_sync (sync_acknowledgment: 0=pending, 1=synced, 2=processed)
D
Visitor's vehicle is recognised on arrival
When the vehicle next passes the camera, the plate matches the allowlist, the barrier opens, and the resident is notified.
Genio Strategy

LPR in the Context of Genio

Singapore (iplus + Hikvision)

  • Existing system is mature — Hikvision LPR cameras are already deployed, webhook integration is live, and full audit logging is operational.
  • AI chatbot for Genio Singapore can query the LPR access logs to answer resident questions like "When did my visitor arrive?" or "What is my vehicle entry history?"
  • Blacklist and repeated entry alerts can be surfaced in the Genio AI chat as real-time security notifications.

Rest of World (Genio Global)

  • Not all regions will have Hikvision — Genio's LPR module should be designed as a camera-agnostic webhook receiver: any LPR camera that can POST a plate number should be supported.
  • The data model (visitor pass, parking log, blacklist, entry/exit event) should be replicated in the Genio NestJS backend as a portable module.
  • Fallback: manual plate entry by security guard (like the current vehicle-add flow) must always work even without hardware cameras.
  • For regions without physical cameras, the AI chatbot can handle visitor pre-registration digitally — resident invites visitor, system generates a QR or OTP at the gate instead of plate recognition.
